📋 Kaise Use Karein

Step 1: Script tag add karo

<script src="https://shivamkumarrj15-sudo.github.io/tsc-manager/tsc-sdk.js"></script>

Step 2: Calculate karo

const result = TSCProAPI.calculate(
  "10 20 30 (5) fb\n45 50 (10) pd",
  { apiKey: "TSC-WEB1-2024-A7X3" }
);
console.log(result);

Custom rate ke saath:

const result = TSCProAPI.calculate(text, {
  apiKey: "TSC-WEB1-2024-A7X3",
  rate: "93/7"
});
